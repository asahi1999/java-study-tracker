## 説明

Java は、実行の前にコード全体を読んで、動かせる形に変える。これを「コンパイル」という。

書き方の間違いがあると、コンパイルで止まる。1行も実行されない。これが「コンパイルエラー」。

エラーには、行の番号と、何がおかしいかの短い文が出る。

1. まず行の番号を見る
2. その行と、1つ上の行の終わりを見る
3. `;` `" "` `( )` `{ }` の数と組を確かめる

エラーの文は英語で出ることがある。`';' expected` は「`;` が無い」という意味。

この画面の Java は、ブラウザの中で動いている。仕事では、自分の PC に入れた JDK で動かす。コードの書き方は同じ。この章の最後に、手元で動かす準備をする。
