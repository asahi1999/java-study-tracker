# 全面改修の前提（ユーザーへのヒアリング結果 2026-11-27）

## ゴール

- Java の勉強をしなくてはならないが、手につかない
- 以前、記録用のアプリ（このリポジトリの v1）を作ったが、結局勉強する気にならなかった
- 今回は「Java の勉強をやろうと思える画期的なもの」が欲しい
- 既存のデザイン・機能に「消してはいけないもの／追加してはいけないもの」はない（完全改修してよい）

## ユーザー

- 専門学校4年。2027年4月からソフトウェアエンジニア（内定先の研修に「Java上級」とあるが、中身は不明）
- Java は文法を少し知っているが、一から学び直したい
- やる気が出ない理由
  - 1回が重く感じて始められない
  - 何から手をつければいいか分からない
  - スマホや遊びに流れる
  - Java 自体が面白くない
- やる気が出るもの
  - 実際に動くものが作れる
  - すぐ結果が出る
  - ゲーム性（レベル、報酬、収集）
- 使う場面: PC に向かえるときだけ。週5時間ほどだが週ごとのばらつきが大きく、事前には分からない
- 期間: 余裕が欲しい（他にもやりたい勉強がある）。週3時間でも2027年2月末に終わる量にし、3月を予備にする
- 手元の環境: macOS、JDK 25（Temurin）、VS Code
- 利用者は本人1人

## 制約

- お金はかけない（有料 API、有料サービスは使わない）
- サーバーなし、ログインなし。GitHub Pages の静的サイト（URL は https://asahi1999.github.io/java-study-tracker/ のまま）
- AI 機能は入れない。代わりに「自分でチャット（Claude など）を開いて質問する」ことを楽にする機能を入れる（問題文、自分のコード、エラーをまとめて、コピーできる質問文を作る）
- Java の実行
  - 短い問題や穴埋め: ブラウザ内（無料・サーバーなしで可能な場合）
  - ある程度の量を書くもの: VS Code で書いて手元の JDK で実行
- PWA にする（インストールとオフラインのみ、通知はなし）
- 就職用ポートフォリオとして扱う（README・テスト・コード品質を保つ）
- アプリ名は変えてよい。リポジトリ名と URL は変えない
- 既存ユーザーデータ（v1 の IndexedDB）は自動で引き継ぐ。無理な部分はエクスポート（JSON）経由で移せるようにする
- 技術スタックは任せる（既存は React 18 + TS + Vite + Tailwind 3 + Dexie。詳細は docs/SPEC.md と README.md）
- UI は日本語。PC を主対象、スマホは最低限
- ゲームの雰囲気は任せる

## 作業のルール

- ブランチ `revamp` で作業し、push は `origin revamp` まで（main への push は自動で本番公開されるので禁止）
- 履歴は残す（force push しない）
- 開発サーバーは、他で使っているポート（3000, 3001, 5000, 7000 など）を避け、起動前に空きを確認する
- lint・整形・型チェック・テスト・ビルドがすべて通る状態でコミットする
