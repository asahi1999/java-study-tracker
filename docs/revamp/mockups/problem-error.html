canMove を書いて、壁の前で止まる

迷路の文字 # は壁です。canMove(map, x, y) が、そのマスに進めるなら true、壁なら false を返すようにしてください。

map[y][x] で、そのマスの1文字が取れます（y が先）。迷路の外側は全部壁なので、はみ出しは気にしなくて大丈夫です。

エラーの説明 コンパイルの段階で止まりました

何が起きた
2行目で、map[y][x]（char・1文字）と "#"（String・文字列）を != で比べています。Java では、この2つの型は比べられません。
よくある原因
1文字は ' '（シングルクォート）、文字列は " "（ダブルクォート）で囲みます。囲み方で型が変わります。
