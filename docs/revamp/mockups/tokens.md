# 案1「ピクセル・ローグライク」デザイントークン

## 方向性（なぜこのアプリに合うか）

- このアプリの核は「標準出力の文字が、そのままタイルのダンジョンになる」こと。ローグライクは昔から「文字＝地図」の文化なので、見た目の約束と仕組みが一致する
- 見た目の主役は1つだけ: **行注釈（文字 → タイル）**。出力の文字列とタイルを同じ行の高さで横に並べ、「1文字＝1マス」を毎回目で確かめられるようにする。ホームの作品、問題の出力、おかえり画面の部屋が同じ描き方
- タイルは 8×8 ドットのオリジナル（石積みの壁、粒のある床、フードの自分、下り階段、松明）。既存ゲームの記号やキャラは使わない
- UI はゲームっぽさを抑える。ドット文字は見出しと数字だけに使い、本文・ボタン・説明は普通の日本語ゴシック。就職用ポートフォリオでも浮かない
- 責めない設計を色で守る: 赤（ember）はコンパイルエラーの場所を示すときだけ。テスト失敗や休んだことには使わない。テストが通らない松明は「灰色で消えている」だけ

## 文字

| 役割         | フォント                     | 使い方                                                                          |
| ------------ | ---------------------------- | ------------------------------------------------------------------------------- |
| 見出し・数字 | DotGothic16（Google Fonts）  | 画面の見出し、レベル、図鑑番号、「次の1ステップ」などのラベル。本文には使わない |
| 本文・ボタン | IBM Plex Sans JP 400/500/700 | 説明、問題文、ボタン                                                            |
| コード・出力 | IBM Plex Mono 400/500/600    | エディタ、出力の文字、エラー原文、日付                                          |

- 文字の大きさ: 本文 15px（行間 1.7）、補足 13px、注記 11〜12px、見出し 17〜22px、主見出し 30〜34px
- 予備は OS 標準（Hiragino Sans / Yu Gothic UI / Menlo）

## 余白・形

- 余白は 4px の格子: 4 / 8 / 12 / 16 / 24 / 32 / 48
- **角丸は使わない**。代わりにピクセルの段（`clip-path`）で角を2px 欠く（パネル・チップ）か、2段（ボタン）にする
- 枠線は 2px（ドット1つ分）。影はぼかさず、ボタンの下だけ 4px のベタ（押せる板に見せる）
- フォーカスは torch-hi の 2px の輪。動きは「図鑑に発見」の光が1回横切るのと、宝箱の光の呼吸だけ。`prefers-reduced-motion` で止める

## タイル（文字 → 絵）

| 文字 | タイル                                       | 文字 | タイル                 |
| ---- | -------------------------------------------- | ---- | ---------------------- |
| `#`  | 石積みの壁                                   | `+`  | 木の扉                 |
| `.`  | 床                                           | `~`  | 水                     |
| `@`  | 自分                                         | `%`  | 苔                     |
| `G`  | 下り階段                                     | `$`  | 宝箱                   |
| `*`  | 松明（壁にかかる）。テスト未通過は消えた松明 | 空白 | 闇（まだ作っていない） |

- 1タイル = 8×8 ドット。表示は 12 / 18 / 24 / 40px（ドットの整数倍）で、ぼかさない
- 対応表にない文字は、床の上にその文字をそのまま描く（出力が何でも絵になる）
- 実装は `tiles.js`（文字列の配列 → SVG）。データと判定には世界観を持ち込まない

## 画面の約束

- 起動直後: 左上の「次の1ステップ」パネルが最初に目に入る。問題名・所要時間・完成図・「始める」が1画面に収まる
- 「1ステップで終えてOK」を、始める前（ホーム）と終えた後（クリアの「ここで終える」）の両方に置く。「ここで終える」は主ボタンと同じ大きさ
- 完走見込みと「今週は休む」は下の段の右端に小さく。遅れの赤表示はない
