## 第1章との関係

- 第1章までで解けるか: 使う前提は、変数・`int`/`String`・連結（`battle + "戦目: "`）・`%`（torch-row・checker-floor）・`++`/`-=`（loops・fix-endless-while）。どれも第1章の必修のカード（variables・arithmetic）にある。`%` の予想問題（ch01.modulo）はおかわりだが、arithmetic のカードで `7 % 2` を見ているので足りる
- `--` は第1章で教えていない。第2章も Starter・Solution では使っていない（間違いの解答 MinusOne だけ。学習者が書いても動くので問題ない）
- 重複: 第1章は `"#".repeat(n)` で壁を描き、第2章は `for` で同じ壁を描く。「なぜ `repeat` でなく `for`？」と思いやすい → loops のカードに1文足した（下記）
- 矛盾: 無し。第1章の `boolean`（`true`/`false`）を、if-else のカードで「比べた結果」とつないだ
- 表記: 第1章は「減る」「付ける」「いちばん」。第2章の「へる」「つける」「一番」をそろえた
- 第1章の damage の解説に「`if` を使わなくても `Math.max` で」とある。第2章の battle-result はそれを受ける形で、食い違いは無い

## 問題ごと

### ch02.if-else（card）

- **指摘1** 「`=` は代入」の「代入」は第0〜1章の教材に出てこない語（第1章は「入れ直す」） → 「`=` は値を入れる記号」に直した
- **指摘2** 比べた結果が第1章の `boolean` と同じものだと分かるように、「（第1章の `boolean` の値）」を足した
- `!` は説明だけで、この章の問題には出ない。困らないので残した

### ch02.which-branch（predict）

- 問題なし。誤答は「`ふらふら`（下の条件を読む）」「2行出る（`else if` も全部動く）」で、どちらもありそう。解説は出力と一致

### ch02.fix-lonely-else（fix）

- 問題なし。`if (…);` の `;` は実際によくある間違い。javac・teavm とも `else-without-if` に当たる（content:verify）
- 間違いの解答（`else if` にする・`else` を消して2行出る）は、エラーの文言に引っぱられてやりそう
- ヒント3は答えに近いが、コードそのものは書いていない

### ch02.switch-ternary（card）

- 問題なし。`switch` 式の `};` の `;`、`,` で値を並べる書き方、`equals` と `isEmpty` がそろっている

### ch02.pick-tile（predict）

- 問題なし。誤答は「`keys > 0` を取り違える」「`,` の2つ目に当たらない」の思いこみで妥当

### ch02.loops（card）

- **指摘** 第1章の `repeat` と同じ壁を `for` で描くので、理由を1文足した（「`for` なら、回ごとに `if` で違う文字を出せる」）。次の torch-row への前ふりにもなる

### ch02.fix-endless-while（fix）

- **指摘1** 時間切れ（既定3000ms）まで学習者を待たせる。実行と判定で2回待つこともある → `timeoutMs: 2000` にした。模範解答は一瞬で終わり、検証の「teavm の実行時間が timeoutMs の 1/3 以下」も通る
- **指摘2** 「へる」「へらす」→「減る」「減らす」（第1章にそろえた）
- 間違いの解答（`slimeHp--` で1ずつ・ループの外で減らす）は妥当。後者は時間切れのまま

### ch02.torch-row（draw）

- **指摘** 「3マスおきに」は「3マス空けて」とも読める（`##*##*##*##` は2マス空き） → 「3マスごとに」に直した
- ヒントは「図で `x` を数える」→「`%` のあまり」→「`if`/`else` で `print`」と段階的。`PrintlnInLoop` はとてもありそう

### ch02.nested（card）

- **指摘** 「どちらも、いちばん内側のループにだけ効く」は、外側のループに書いた `break` も内側に効くと読める → 「その語を囲むループのうち、いちばん内側の1つにだけ効く」に直した

### ch02.diagonal（predict）

- 問題なし。誤答は「`continue` を `break` と思う」「`continue` が何も飛ばさないと思う（5文字）」で妥当。解説は出力と一致

### ch02.walled-room（draw）

- 並び順を 120 → 110 にした（必修を先に）
- ヒント2「ループの `<` の右の数から考える」が `OffByOne`（`y == 5`）に効く。`AndInstead`・`TopBottomOnly` も妥当

### ch02.checker-floor（draw、おかわり）

- 並び順を 110 → 120 にした
- 偶数・奇数を `% 2` で見分けることは、第1章の arithmetic のカード（`7 % 2`）で見ている

### ch02.room-door（fill）

- **指摘** 「つける」→「付ける」（題も「扉を付ける」に）
- ひな形が walled-room の答えを含むが、walled-room のあとなので問題ない。解説の「扉の `if` が壁より上」は正しい

### ch02.dig-tunnel（fill）

- 問題なし。ひな形のままだと `#.....&.....#`。ヒント3は `continue` との違いとカードを指すだけで、答えは書いていない

### ch02.battle-result（implement）

- **指摘** 「一番上」→「いちばん上」
- 4戦目（魔物の HP がマイナス）で `EqualsZero` が、5戦目（両方0）で `HeroFirst` が落ちる。場面の作り方がよい

### ch02.element-match（implement、おかわり）
